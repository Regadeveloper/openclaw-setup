# OpenClaw Setup

Testing ground for Fast-Follow Development workflow with AI agents.

Based on: https://www.conor.fyi/writing/working-april-26

## Workflow

- 📱 Capture bugs/features from the app
- 💬 Send to Claudio via WhatsApp/Telegram
- 🤖 Claudio opens GitHub issues with full spec
- 🏷️ Labels define priority, risk, clarity, blast radius
- 🔀 Parallelize work across lanes
- ✅ Agents (Claude) pick up and create PRs
- 🔍 Review, merge, close

## Quick Start

1. Install labels: `bash scripts/install-labels.sh`
2. Check issue templates: `.github/ISSUE_TEMPLATE/`
3. Create an issue from a screenshot
4. Tag with appropriate labels
5. Claudio kicks it off
